# سلب مسئولیت و استفاده مجاز

این پروژه برای آموزش، مستندسازی، دفاع و ارزیابی امنیتی دارای مجوز تهیه شده است.

Hydra را فقط روی سیستم شخصی، محیط آموزشی کنترل‌شده یا سامانه‌ای اجرا کنید که برای آزمون Authentication آن مجوز کتبی دارید. Attempt تکراری می‌تواند Account Lockout، Incident Response یا اختلال سرویس ایجاد کند.

این Repository عمداً Target واقعی شخص ثالث، Credential واقعی، Password Dump، روش MFA/CAPTCHA/Lockout Bypass و Anti-detection Guidance منتشر نمی‌کند.

مسئولیت اخذ مجوز، رعایت قانون و Policy، Scope، Timing و Evidence Handling بر عهده اجراکننده است.
