# معرفی بنیادین Hydra

<div class="chapter-meta">هدف: قبل از اجرای هر دستور، جایگاه Hydra، محدوده این مرجع و مرز مجوز را روشن کنید.</div>

Hydra یک ابزار خط فرمان برای آزمون احراز هویت است که می‌تواند Candidateهای نام کاربری و رمز عبور را روی سرویس‌های مختلف و فرم‌های ساده Login آزمایش کند. اسناد اولیه‌ای که مبنای این پروژه هستند آن را برای آموزش امنیت احراز هویت معرفی می‌کنند؛ پروژه upstream نیز Hydra را ابزار Proof-of-Concept برای پژوهشگر و مشاور امنیتی توصیف می‌کند.

مرز این مرجع روشن است: **سیستم شخصی، محیط آزمایشگاهی کنترل‌شده یا ارزیابی دارای مجوز صریح**. این پروژه راهنمای پنهان‌سازی فعالیت، Bypass کردن MFA/CAPTCHA/Lockout یا هدف‌گیری شخص ثالث ارائه نمی‌کند.

## Hydra چه چیزی را ارزیابی می‌کند؟

یک تمرین استاندارد چهار بخش دارد:

1. Target مشخص و داخل Scope مثل `192.168.56.10`؛
2. Service/Module مانند `ssh`، `ftp` یا `http-post-form`؛
3. مجموعه کوچک و مصنوعی Username/Password؛
4. قاعده مشخص برای تشخیص شکست یا موفقیت احتمالی Login.

Hydra تلاش‌های احراز هویت تکراری را خودکار می‌کند. بنابراین هم می‌تواند ضعف Password Policy را نشان دهد و هم برای اعتبارسنجی Lockout، Rate Limit و Detection مفید باشد. همین ویژگی در صورت استفاده بی‌احتیاط می‌تواند حساب را Lock کند یا ترافیک احراز هویت زیادی تولید کند.

## مبنای محتوای پروژه

دو سند فارسی اولیه موضوعات نصب در Kali، فایل‌های Credential، آزمایشگاه SSH/FTP، Syntax فرم HTTP/HTTPS، شرط `F=`، False Positive، CSRF، CAPTCHA، Rate Limiting و الزامات استفاده مجاز را پوشش می‌دهند. این پروژه همان مطالب را به ساختار حرفه‌ای فارسی/English تبدیل کرده و بخش‌های نگهداری، گزارش‌دهی، Accessibility و QA را اضافه می‌کند.

برای رفتار دقیق هر نسخه، `hydra -h`، دستور `hydra -U <module>` و مستندات upstream را بررسی کنید.

## قبل از ادامه

Target مجاز، بازه زمانی، حساب تست، Candidateهای مصنوعی، سیاست Lockout و Stop Condition را مشخص کنید. اگر هرکدام نامشخص است، اجرای تست را عقب بیندازید.
