# Disclaimer and authorized use

This project is for education, documentation, defensive validation, and explicitly authorized security assessment.

Use Hydra only on systems you own, controlled training environments, or systems for which you have written permission to perform authentication testing. Repeated login attempts can lock accounts, trigger incident response, or affect service availability.

This repository intentionally avoids real third-party targets, real credentials, leaked password collections, MFA/CAPTCHA/lockout bypass instructions, and anti-detection guidance.

The operator is responsible for authorization, applicable law, organizational policy, scope, timing, and safe evidence handling.
