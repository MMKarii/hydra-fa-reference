# Bilingual Hydra glossary

| English term | Persian equivalent / alias | Search aliases |
|---|---|---|
| Authentication testing | آزمون احراز هویت | login testing, تست ورود |
| Password auditing | ممیزی رمز عبور | credential audit, ارزیابی رمز |
| Login | نام کاربری / ورود | username, user, کاربر |
| Password | رمز عبور | pass, credential, گذرواژه |
| Wordlist | فهرست آزمایشی | candidate list, لیست رمز |
| Module | ماژول سرویس | protocol module, service |
| SSH | اس‌اس‌اچ | secure shell |
| FTP | اف‌تی‌پی | file transfer |
| HTTP POST form | فرم POST وب | `http-post-form` |
| HTTPS POST form | فرم POST امن وب | `https-post-form` |
| `^USER^` | جای‌نگهدار نام کاربری | username placeholder |
| `^PASS^` | جای‌نگهدار رمز عبور | password placeholder |
| Failure condition | شرط شکست | `F=`, failure string |
| Success condition | شرط موفقیت | `S=`, success string |
| False positive | مثبت کاذب | نتیجه اشتباه |
| CSRF token | توکن CSRF | anti-CSRF token |
| CAPTCHA | کپچا | anti-automation challenge |
| Rate limiting | محدودیت نرخ | throttling, کاهش نرخ |
| Account lockout | قفل حساب | lockout policy |
| MFA | احراز هویت چندعاملی | multi-factor authentication |
| Authorized scope | محدوده مجاز | written scope, مجوز |

Official option names and module names remain in English so users can search both language editions consistently.
