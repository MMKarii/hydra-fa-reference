# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-09-16

### Added
- Complete bilingual Persian and English Hydra documentation.
- Mirrored 14-chapter structure plus learning path, cheat sheet, glossary, references, and disclaimer.
- Lab-only SSH, FTP, and simple HTTP/HTTPS form examples grounded in the supplied training documents.
- Defensive guidance for CSRF, CAPTCHA, rate limiting, lockout, MFA, monitoring, and false-positive validation.
- High-quality Hydra banner, responsive RTL/LTR styling, and 1280×640 social preview.
- CC BY 4.0 project documentation license.
- Governance files, issue/PR templates, security policy, and repository metadata guidance.
- Automated structure, links, anchors, translation freshness, external link, accessibility, and strict MkDocs checks.
- `/latest/` and `/v1.0/` publication layouts.

### Safety
- Removed the real target hostname from the uploaded source material.
- Public examples use private lab addresses and synthetic credentials only.
- No guidance for MFA/CAPTCHA/lockout bypass or anti-detection is included.
