# Security Policy

## Scope

This repository contains documentation, publishing automation, and QA tooling for the bilingual Hydra reference. Vulnerabilities in Hydra itself are out of scope and should be reported to the upstream THC-Hydra project.

## Reporting a repository issue

Do not open a public issue containing credentials, tokens, real customer identifiers, private target inventories, sensitive authentication output, or exploit-sensitive repository details.

When GitHub Private Vulnerability Reporting is available, use it. Otherwise contact the maintainer privately through the contact options on the `MMKarii` GitHub profile and include only safe reproduction data.

## Responsible use

All documentation examples are intended for controlled labs and explicitly authorized assessments. This repository does not authorize testing third-party systems.
